# Haryana Waste Industry Database

Editable business-development database for Haryana industries, industrial clusters, waste streams, reuse/recycling routes and waste-business opportunities.

## Core features
- Coverage framework for all 22 Haryana districts
- Industry and industrial-area records
- Waste/by-product mapping
- Hazardous/regulated handling flag
- Likely buyer/reuse route
- Business opportunity and priority
- Verification status and source
- Manual Add / Edit / Delete in the browser
- Search and filters
- JSON and CSV export
- JSON import
- Browser localStorage persistence

## Run locally

```bash
python -m http.server 8080
```

Open `http://localhost:8080`.

## Important
This is a business-development database, not a regulatory inventory. Materials such as used oil, e-waste, batteries, biomedical waste, chemical residues, plating/paint sludge and other hazardous waste may require CPCB/HSPCB registrations, authorizations and movement only through authorized handlers/recyclers.
